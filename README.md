# Vineta Store Annual Sales Analysis – Excel Dashboard

## 📊 Project Overview

This project is an **Excel-based Sales Analysis Dashboard** created to analyze the annual sales performance of Vineta Store for 2025.

The objective of this project is to transform raw sales data into meaningful business insights using **Microsoft Excel**, including data cleaning, data analysis, PivotTables, PivotCharts, and an interactive dashboard.

This project was created as part of my learning journey as a **beginner Data Analyst**, with a focus on developing practical skills in data analysis and visualization.

## 🎯 Business Objective

The main objectives of this analysis are:

* Analyze overall sales performance
* Understand customer purchasing patterns
* Identify important sales trends
* Analyze order and sales distribution
* Compare different categories and segments
* Create an interactive dashboard for easy decision-making
* Present raw data in a clear and understandable visual format

## 🔍 Project Workflow

### 1. Data Collection

Used the provided Vineta Store sales dataset for the analysis.

### 2. Data Cleaning

Checked the dataset for issues such as missing values, duplicate records, incorrect formats, and inconsistencies.

### 3. Data Preparation

Prepared the data for analysis by organizing fields and creating the required calculations.

### 4. Data Analysis

Used Excel functions, PivotTables, and PivotCharts to analyze sales and customer-related information.

### 5. Dashboard Development

Created an interactive Excel dashboard containing charts, KPIs, and visual summaries.

### 6. Insights

Used the dashboard to identify important patterns and trends in the store's sales data.
